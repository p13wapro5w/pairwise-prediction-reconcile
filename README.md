# pairwise-prediction-reconcile

200ms 延迟下松开摇杆，角色还会往前滑半米，服务器校正时直接瞬移回墙角：客户端预测按 60Hz 推进，服务器 tick 是 30Hz，同一帧输入被应用两次；丢包后没有按序号重放，预测状态和服务器越差越远；回滚只回位置，技能冷却、弹药和载具油量没回滚；延迟补偿把别人倒带到过去，命中判定却用当前帧；载具物理在客户端单独模拟，校正时角色和载具脱节；预测层忽略碰撞，穿墙后服务器硬拉；时间同步只用一次 RTT，抖动时偏移累积；输入缓冲没按序号去重，快速连点被放大；校正阈值固定，慢速漂移永远不纠；多线程预测和渲染共享状态，读到半更新快照；断线重连后房间 tick 变了，旧输入还在队列；协议版本升级后状态字段增删，旧客户端解析错位；服务器回滚时没有冻结特效和音频，表现层闪回。net/prediction_reconcile.py 是核心，tests/test_prediction_reconcile.py 15个红。要修的是：tick 对齐；丢包重放；全状态回滚；延迟补偿一致；载具绑定；预测碰撞；持续时钟同步；输入去重；自适应阈值；状态快照；重连清队列；协议版本兼容；表现层冻结。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
